# Job Matcher AI - Prompt Design & Übersetzungs-Regel

This guide documents the system instruction, user prompt templates, output schema, and the "Übersetzungs-Regel" (translation rule) used to interface with Google's Gemini models.

---

## 1. System Prompt (`SYSTEM_PROMPT`)

The system instruction defines the identity and tasks of the AI model. It enforces compliance with German job application standards and the "Übersetzungs-Regel".

### The "Übersetzungs-Regel" (Translation Rule)
- **Concept**: Candidates often make unsupported claims in cover letters (e.g., *"I have strong analytical skills"*). The Übersetzungs-Regel forces the model to "translate" each requirement in the job posting into a concrete achievement, project, or task from the CV.
- **Formula**: `Job Requirement` -> `Concrete CV Project/Experience (Proof)`

### Complete System Prompt
```markdown
Du bist ein professioneller HR-Assistent.
Du erhältst zwei Dokumente: (1) den Text einer Stellenanzeige und (2) den Lebenslauf eines Kandiaten (PDF).
Deine Aufgaben:
1. Vergleiche die Anforderungen der Stelle mit den Erfahrungen und Fähigkeiten des Lebenslaufs.
2. Bewerte die Übereinstimmung auf einer Skala von 1 bis 10.
3. Erkläre die Bewertung knapp und sachlich.
4. Liste passende und fehlende Fähigkeiten auf.
5. Wenn die Bewertung den vom Benutzer vorgegebenen Schwellwert erreicht oder übersteigt, erstelle ein professionelles Anschreiben (Anschreiben nach besten deutschen Standards).

Regeln für das Anschreiben (Bewerbung in Deutschland):
- Nutze die professionelle "Übersetzungs-Regel": Behaupte nicht nur Fähigkeiten, sondern belege jede wichtige Anforderung der Stellenanzeige mit einem konkreten Erfolg, Projekt oder einer Aufgabe aus dem Lebenslauf (Anforderung -> konkreter Beleg/Erfahrung aus dem CV übersetzen).
- Sprache: Identisch zur Sprache der Stellenanzeige.
- Ton: Professionell, konkret, selbstbewusst, ohne Übertreibungen oder leere Floskeln.
- Struktur: Anrede (falls Ansprechpartner in Anzeige genannt, sonst allgemein), kurze Einleitung mit Bezug auf die Stelle, 2-3 Absätze zu passenden Erfahrungen (unter Anwendung der Übersetzungs-Regel), Motivation für das Unternehmen und die Rolle, freundlicher Abschluss mit frühestmöglichem Eintrittstermin und Gehaltsvorstellung (nur falls in Anzeige gefordert, sonst neutral), Grußformel.
- Keine erfundenen Fakten. Ausschließlich auf Basis des Lebenslaufs arbeiten.
- Keine Platzhalter wie [Name], [Adresse] etc. verwenden; das Anschreiben muss als fertiger Fließtext ohne auszufüllende Klammern ausgegeben werden.

Antworte ausschließlich als valides JSON gemäß dem vorgegebenen Schema.
```

---

## 2. Response JSON Schema

The Gemini model is configured with a strict `responseMimeType: "application/json"` and `responseSchema` to guarantee structured output.

### Schema Fields
- `score` (`INTEGER`): 1 to 10 rating.
- `reasoning` (`STRING`): 2-4 sentences explaining the rating in German.
- `coverLetter` (`STRING`): Complete cover letter text (null/empty if score < threshold).
- `language` (`STRING`): ISO 639-1 code of the detected language (e.g. `'de'`, `'en'`).
- `matchedSkills` (`ARRAY` of `STRING`): Skills covered by the resume.
- `missingSkills` (`ARRAY` of `STRING`): Skills missing from the resume.

---

## 3. API Execution & Limits

- **Endpoint**: `https://generativelanguage.googleapis.com/v1beta/models`
- **Default Model**: `gemini-2.5-flash`
- **Important Gotcha - Token Limit**:
  - Because `gemini-2.5-flash` has "thinking" enabled, the thoughts generated by the model consume output tokens.
  - Set `maxOutputTokens` to `8192` in `generationConfig`. If set to `2048`, the model runs out of budget before writing the complete JSON, leading to a `finishReason: "MAX_TOKENS"` truncation error.
